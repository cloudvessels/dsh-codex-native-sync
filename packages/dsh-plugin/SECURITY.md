# 权限与问题报告

本包是本地聊天同步工具，能够读写聊天和状态文件。配套桥接读取 Codex 会话目录与数据库；插件通过 DSH 公开会话服务修改已绑定会话。可选工具记录只保存已完成调用的数据，不执行导入的命令，也不导入私有推理。请仅对可信本机软件使用。

同步 HTTP 服务限制在回环地址并使用本机令牌。令牌、原始聊天、数据库、绝对机器配置和升级日志不要作为公开 Issue 附件。关闭总开关停止同步；关闭自动更新停止后续自动升级。自动升级信任本项目的 GitHub 发布权限及 HTTPS/SHA-256 校验，摘要校验不能防御发布账户失陷；严格审阅环境应关闭自动更新，审阅固定 Commit 后手工更新。

商城的 `user-reviewed` 更新审批与套件自动更新是不同机制。不得以已安装或校验通过声称安全审计完成，也不得将本包归类为无文件/网络/命令权限。

一般问题请在 [项目 Issues](https://github.com/cloudvessels/dsh-codex-native-sync/issues) 提交脱敏复现；安全问题请使用仓库的私密安全报告入口（若未启用，仅公开描述受影响版本和问题类别，请维护者提供私密渠道），不要公开密钥、聊天或可利用的敏感细节。本项目没有保证响应时限。

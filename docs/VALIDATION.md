## 0.3.1 修复审查

日期：2026-10-27。审查基线为 `381bb89`，范围为发布仓库，不替换本机正在使用的安装。

## 审查结果

| 原问题 | 修复与证据 |
|---|---|
| 发布模块仍引用旧目录，独立 DSH 安装副本缺依赖 | 修正静态相对导入，DSH 工具模块包内自带；从含空格的独立 profile 加载宿主，运行原生同步链路 |
| 安装失败未恢复被移走的旧包 | 完整暂存后发布；在清单发布处注入失败，验证旧包、用户配置、数据与原 profile 都恢复 |
| 重归属仅换 sessionId，账本与去重依据未一起迁移 | 原消息 ID、账本批次、队列游标和身份命名空间一起保留；验证双映射发布失败、准备中断、活动桥接拒绝与迁移期间源消息变化 |
| 开发机路径写死、空的旧采集路径阻断启动 | 使用宿主依赖或显式配置；零旧聊天变量、零绑定时启动服务且不生成空聊天 |
| 标题投影读错形状，重复写同名标题，截断误报成功 | 列表与改名统一读取原生字符串投影；验证幂等、改名跟随和截断报错，使用原生标题配置验证长中文标题 |

补充审查复现了两个迁移边界：缺失账本会被当作空账本继续，超过 1000 条公开消息会超出单批限制。已分别改为写前拒绝与分批复制，并增加了先失败、修复后通过的测试。
